# Daheng Galaxy runtime libraries

Place the Daheng Galaxy runtime shared library here when you want to build
without installing the official SDK system-wide:

- `amd64/libgxiapi.so` for x86_64
- `arm64/libgxiapi.so` for aarch64 / Jetson

The headers are already under `io/daheng/include`. The runtime library still
comes from Daheng's SDK package, so keep its license terms in mind before
redistributing it.
